# 🩺 Disease Prediction API

A Machine Learning-powered REST API built with **FastAPI** and **TensorFlow/Keras** that predicts diseases from user-provided symptoms.

The API validates symptoms against the training vocabulary, converts them into a binary feature vector, performs model inference, and returns the most likely disease along with the top 5 predictions.

---

## 🚀 Features

- FastAPI REST API
- TensorFlow/Keras disease prediction model
- Symptom validation and preprocessing
- Binary symptom vector generation
- Top-5 disease predictions
- Health monitoring endpoint
- Automatic Swagger/OpenAPI documentation
- Structured request/response validation using Pydantic

## ⚙️ How It Works

### 1. Input Symptoms

```json
{
  "symptoms": [
    "fatigue",
    "sweating",
    "weight_loss"
  ]
}
```

### 2. Validation & Preprocessing

The API:

- Normalizes symptom names
- Removes duplicates
- Validates symptoms against the training vocabulary
- Rejects unknown symptoms
- Generates a binary feature vector

### 3. Model Prediction

The TensorFlow model predicts probabilities for all disease classes.

### 4. Response Generation

The label encoder converts predicted class indices back into disease names.

Example response:

```json
{
  "prediction": "Jaundice",
  "confidence": 0.429,
  "top_predictions": [
    {
      "disease": "Jaundice",
      "confidence": 0.429
    },
    {
      "disease": "Bronchial Asthma",
      "confidence": 0.166
    }
  ]
}
```

## 📡 API Endpoints

### GET /

Returns API status.

**Response**

```json
{
  "name": "Disease Prediction API",
  "status": "running"
}
```

---

### GET /health

Checks API and model health.

**Response**

```json
{
  "status": "healthy",
  "model_loaded": true
}
```

---

### POST /predict

Predict disease from symptoms.

**Request**

```json
{
  "symptoms": [
    "fatigue",
    "sweating",
    "weight_loss"
  ]
```

```json
  "confidence": 0.429,
  "top_predictions": [
    {
      "disease": "Jaundice",
      "confidence": 0.429
```

## 🛠️ Installation

### Clone Repository

```bash
git clone https://github.com/<username>/sanjeevni-ml_api.git
cd sanjeevni-ml_api
```

### Create Virtual Environment

**Windows**

```bash
python -m venv venv
venv\Scripts\activate
```

**Linux / macOS**

```bash
python3 -m venv venv
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```
